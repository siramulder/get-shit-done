# PRD: Task Priority App – MVP1

Sep 26, 2026

## Problem Statement

คนทำงานคนเดียวหรือทีมเล็กมักมีรายการงานกระจัดกระจาย และไม่มีวิธีง่าย ๆ ในการตัดสินใจว่า "วันนี้ควรทำอะไรก่อน" เครื่องมือที่มีอยู่ (Asana, Monday.com, Notion) ซับซ้อนเกินความจำเป็นสำหรับความต้องการพื้นฐานนี้ ทำให้ผู้ใช้เสียเวลาตั้งค่าหรือเลี่ยงการใช้งานไปเลย ผลคือต้องตัดสินใจซ้ำ ๆ ทุกวันโดยไม่มีระบบช่วย และงานสำคัญอาจตกหล่นไป

## Goals

- ผู้ใช้สามารถเพิ่มงานและจัดลำดับได้ภายใน 10 วินาทีแรกที่เปิดแอป (ไม่มี onboarding ซับซ้อน)
- ผู้ใช้กลับมาเปิดแอปทุกวัน (daily active use) เพื่อดู/จัดลำดับงาน
- ผู้ใช้รู้สึกว่าตัดสินใจ "ควรทำอะไรก่อน" ได้ง่ายกว่าการเขียนลิสต์แบบเดิม
- ระบบเก็บข้อมูลได้แม่นยำ 100% ไม่มีงานหาย

## Non-Goals

- **Deadline / due date** — เก็บไว้ทำใน v1.1 เพื่อให้ MVP1 เรียบง่ายที่สุด
- **Smart/AI prioritization** — ยังไม่มีข้อมูลพฤติกรรมผู้ใช้พอจะทำแนะนำอัตโนมัติ
- **Collaboration / sharing กับทีม** — เพิ่มความซับซ้อนด้าน permission และ sync ที่ยังไม่จำเป็นสำหรับ personal use
- **Categories, tags, subtasks** — ทำให้การเพิ่มงานช้าลง ขัดกับเป้าหมาย "เร็วและง่าย"
- **Analytics/reporting** — ยังไม่มีข้อมูลผู้ใช้มากพอที่จะทำ insight ที่มีประโยชน์

## User Stories

- ในฐานะผู้ใช้ ฉันต้องการเพิ่มงานใหม่ด้วยการพิมพ์ชื่อสั้น ๆ เพื่อบันทึกงานได้เร็วโดยไม่ต้องกรอกรายละเอียด
- ในฐานะผู้ใช้ ฉันต้องการลาก-วางหรือกดปุ่มขึ้น/ลงเพื่อจัดลำดับงานเอง เพื่อให้ลิสต์สะท้อนสิ่งที่สำคัญที่สุดตอนนี้
- ในฐานะผู้ใช้ ฉันต้องการกดทำเครื่องหมายว่างานเสร็จแล้ว เพื่อให้ลิสต์วันนี้เหลือแต่งานที่ยังไม่เสร็จ
- ในฐานะผู้ใช้ ฉันต้องการเห็นรายการงานที่ทำเสร็จแล้วในวันนั้น เพื่อรู้สึกถึงความคืบหน้า
- ในฐานะผู้ใช้ ฉันต้องการให้งานที่ค้างจากเมื่อวานปรากฏในลิสต์วันนี้อัตโนมัติ เพื่อไม่ต้องจัดใหม่เอง

## Requirements

### Must-Have (P0)

- [ ] เพิ่มงานด้วยชื่อ (title) อย่างเดียว — ไม่มี field บังคับอื่น
- [ ] จัดลำดับงานด้วย drag & drop และปุ่ม ↑ ↓
- [ ] กดทำเครื่องหมายงานว่าเสร็จ → ย้ายไปหมวด "Done"
- [ ] หน้า "Today" แสดงงานที่ยังไม่เสร็จตามลำดับที่ตั้งไว้
- [ ] บันทึกข้อมูลอัตโนมัติ (persist) ไม่ต้องกดเซฟเอง
- [ ] งานที่ยังไม่เสร็จยกยอดไปวันถัดไปอัตโนมัติ

### Nice-to-Have (P1)

- [ ] Undo หลังกดทำเสร็จ/ลบงานผิด
- [ ] แก้ไขชื่องานหลังเพิ่มแล้ว
- [ ] ดูสรุปงานที่ทำเสร็จของวันนั้น

### Future Considerations (P2)

- [ ] Deadline / due date (v1.1)
- [ ] Smart prioritization ตาม deadline (v1.2)
- [ ] Sharing/collaboration กับทีม (v2)
